# TodoApp

Aplikasi **TodoApp** merupakan aplikasi sederhana untuk membantu pengguna dalam mengelola daftar aktivitas atau tugas sehari-hari. Aplikasi ini dikembangkan menggunakan React Native melalui platform Expo Snack.

## Tampilan Aplikasi

![Tampilan TodoApp](https://github.com/user-attachments/assets/a959acee-4941-4d04-a21e-f8ec81f943b5)

## Teknologi yang Digunakan

- **React Native** – Framework untuk pengembangan aplikasi mobile.
- **Expo Snack** – Platform online untuk mengembangkan dan menjalankan aplikasi React Native.
- **JavaScript** – Bahasa pemrograman yang digunakan dalam pengembangan aplikasi.

## Persyaratan

Untuk menjalankan aplikasi, pastikan sudah memiliki:

- Node.js
- NPM (Node Package Manager)
- Expo Go (untuk menjalankan aplikasi pada smartphone)

## Cara Menjalankan Aplikasi

1. Clone repository

   ```bash
   git clone https://github.com/ynrwy/TodoApp.git
   ```

2. Masuk ke direktori project

   ```bash
   cd TodoApp
   ```

3. Install dependencies

   ```bash
   npm install
   ```

4. Jalankan aplikasi

   ```bash
   npx expo start
   ```

5. Scan QR Code menggunakan aplikasi Expo Go atau jalankan melalui Android Emulator maupun iOS Simulator.

## Pengembangan Aplikasi

Pengembangan aplikasi dilakukan melalui file `App.js`. Perubahan kode dapat langsung dilihat melalui fitur preview pada Expo Snack menggunakan smartphone atau emulator.
